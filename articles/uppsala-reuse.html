スウェーデン / 解体・再利用

壊した建物は資源になる？スウェーデン・ウプサラの実証

解体材を次の建築へつなげるには、回収量の測定・品質・コスト・工程が必要。

GLOBAL PROJECT NOTEスウェーデン実証進行中

スウェーデンのUppsalaでは、既存建物の解体からどこまで建材を再利用できるか、循環型建築の課題を検証する動きが報告されています。

この記事の結論

「すべて再利用できる」という事例ではありません。分別、汚染物質の確認、強度・品質、保管と需要のタイミングを揃えることが課題です。

プロジェクトの概要

場所スウェーデン・ウプサラ
対象UlleråkerやGottsunda地区での試行
実務テーマ解体材の再利用率と障壁を記録・検証

回収と再利用の間に「保管と引渡し」の工程がある

ウプサラ市のScale Up公式紹介では、Ulleråkerで解体・分解した建材を保管し、市の内部だけでなく外部の建設事業者にも再利用・販売する方針が説明されています。回収した瞬間に再利用が完了するのではなく、次の使い手が決まるまで材料を管理する仕組みが必要だと分かります。これは事業の取り組み・方針を示すもので、全回収材が再利用された実績の証明ではありません。

編集部提案：撤去前に「材料の引継ぎ票」をつくる

記録すること次工程で役立つ理由
元の建物・部位・材料番号どこから来た材料かを追跡し、履歴を失わない
寸法・数量・状態と写真設計側が使える数量と必要加工を検討できる
性能資料・有害物質調査の有無不足する試験や使用可否の確認を引渡し前に整理できる
撤去・搬送・保管方法回収後の破損や混在を防ぎ、保管費を含む工程を考えられる
引渡し先・時期・責任範囲置き場が埋まる前に次の需要と調整できる

日本で応用するなら、まず再利用先が求める性能と数量から逆算し、回収候補を選ぶ方法が考えられます。木材なら腐朽や薬剤処理の履歴、金属なら腐食や接合部の損傷、外装材なら再利用先に必要な防火・断熱性能を確かめます。利点は、解体後に使い道を探して長期保管する手戻りを減らしやすいこと。強度や防火等の性能を確認できない部材、汚染・石綿等の疑いを解消していない材料は、外観だけで採用しません。再利用品の法令適合、試験、保証、廃棄物としての扱いは国内条件で確認が必要です。表は編集部の実務整理で、ウプサラ市の実際の管理帳票ではありません。

日本の現場に持ち帰れる発想

海外で実現した手法を、そのまま日本の条件に当てはめることはできません。設備・建築・土木に共通する検討項目として、次の3点を整理します。

  1. 解体前の建材調査と分類精度
  2. 再利用先の仕様・認証・品質保証
  3. 撤去工法の選択は回収材を傷めない条件も含める

「面白い」と「採用できる」の間

紹介した建物や技術が優れていても、法規制、気候、保守体制、建材供給、施工者の技能、周辺住民の理解によって実用性は変わります。記事の数値・実績は原則として発表元の条件に限定し、国内での適用やコスト削減効果は現場ごとに再検証する必要があります。

IDEA TO ACTION

工法・事業のアイデアに転用するなら

  1. 解決したい課題を「騒音」「材料」「搬入」「維持管理」などに分解
  2. 既存手法との比較表を作り、改善効果を測れる指標を選ぶ
  3. 技術の供給元・施工実績・許認可・保証条件を調べる
  4. 小さな試験・モデル事業から導入可否を判断する
